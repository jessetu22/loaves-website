# LOAVES

Slide into comfort. A responsive four-page footwear website with a monochrome editorial design.

## Files

- `index.html`: Home
- `about.html`: About
- `products.html`: Footwear and shopping links
- `contact.html`: Email and social links
- `assets/style.css`: Shared styling and mobile layouts

## Preview

Open index.html in a browser, or run `python3 -m http.server 8000` from this folder and open http://localhost:8000. No dependencies or build step required.

## GitHub Pages

In repository Settings > Pages, select Deploy from a branch, choose main and / (root), then Save. Availability for a private repository depends on your GitHub plan. The published site will normally be publicly accessible.

## Editing

Edit HTML for text and links, and assets/style.css for styling. Visual panels currently use typographic artwork; replace them with original product photography when available. Contact links open the visitor's email app. Checkout and a contact-form backend are not included.
